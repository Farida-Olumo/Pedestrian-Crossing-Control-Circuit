# Pedestrian Crossing Control Circuit

## Overview

This project focuses on the design and implementation of an electronic pedestrian crossing control circuit.

The system explores the use of electronic components, signal sequencing, and control logic to coordinate pedestrian and vehicle traffic indications.

The project demonstrates fundamental concepts in electrical and electronics engineering, including circuit design, digital control, and hardware implementation.

## Project Objectives

- Design an electronic pedestrian crossing control circuit.
- Implement traffic signal sequencing.
- Coordinate pedestrian and vehicle crossing indications.
- Integrate electronic components into a functional circuit.
- Evaluate the operation of the completed system.

## System Features

### 1. Traffic Signal Control

The circuit controls the sequence of traffic-light indications.

### 2. Pedestrian Crossing Indication

The system provides an indication for pedestrian crossing as part of the signal sequence.

### 3. Timing and Sequencing

Control logic determines the order and duration of the signal states.

### 4. Circuit Integration

The project combines electronic components and control logic to implement the crossing system.

### 5. Evaluation
- Signal sequence accuracy
- Timing behaviour
- Circuit functionality
- Observed limitations

## Future Improvements

- Investigate adaptive traffic signal timing.
- Explore sensor-based vehicle detection.
- Incorporate additional pedestrian safety features.
